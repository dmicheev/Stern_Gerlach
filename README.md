# ⚛ Stern-Gerlach

![Stern-Gerlach](docs/screenshot-main.png)

Интерактивная 3D-эмуляция опыта Штерна-Герлаха и **теста неравенства Белла** (CHSH)
в духе эксперимента Хансена (Hensen et al., Nature 526, 682 (2015)).

Два режима (переключатель в шапке):

## 1. Каскад (дерево пучков)

Пучок атомов серебра из печи проходит через магниты и оставляет «осадок» на экране.
**Аппараты ставятся на конкретный пучок**: источник даёт корневой луч, каждый магнит
делит его на два выходных (↑/↓) со своими траекториями; следующий магнит привязывается
к выбранной ветви (селектор «Пучок» в карточке), встаёт на её геометрию и видит только
её частицы. Классика предсказывает сплошную полосу — квантовая механика даёт
дискретные пятна.

- Маршрутизация по пучкам: дерево любой глубины (SGz → ветвь ↑ → SGx → …), лучи
  ветвей рисуются в 3D до экрана, позиции магнитов на ветвях вычисляются из отклонения
- **Три модели**: классика (сплошная полоса), полуклассика (квантованный спин, ветви
  cos²(θ/2)), квантовая (волновой пакет ψ(x,z,t) — суперпозиция гауссовых ветвей)
- «Классика-призрак», гистограмма попаданий (±80 мм), таблица ветвей, таймлайн

## 2. Белл CHSH (запутанные пары)

Как в реальном loophole-free тесте: источник запутанных пар |ψ⁻⟩ в центре, две
станции (A и B), каждая с **двумя базисами** (a₀,a₁ / b₀,b₁), случайный выбор базиса
на каждую пару («QRNG»), двухпортовые детекторы, живая статистика CHSH:

- **Квантовая модель**: E(a,b) = −cos(θa−θb) → S до 2√2 (нарушение неравенства)
- **Локальный реализм**: скрытые параметры φ → S ≤ 2 всегда (теорема Белла) —
  тот же сетап, другая «физика»: прямая демонстрация, почему запутанность нельзя
  свести к предопределённым значениям
- Слайдеры «дыры»: эффективность детекторов η и видность V
- Живая таблица корреляций ⟨x·y⟩ по 4 комбинациям базисов, бегущий график S(N)
  с линиями 2 и 2√2, пресет «Hensen 2015» (0°/90° / −139.7°/+139.7°)

Скриншот рабочего режима: `docs/sg-bell-quantum.png`.

## Учебные аннотации

Проект — учебное пособие: каждое устройство в 3D-сцене подписано карточкой
(печь, коллиматор, анализаторы с живыми значениями θ и G, экран-детектор,
источник пар и станции в режиме Белла), каждый параметр, гистограмма и число
имеют «?»-подсказку с формулами и объяснением разницы подходов (RU/EN).

## Разбор экрана по клику

Клик по экрану-детектору (каскад) или по двухпортовым детекторам станции
(режим Белла) открывает разбор: 2D-распределение попаданий (вид на пластину,
z × y), гистограмму N(z) / исходы по базисам с маргиналами ~50%, живые счётчики
и подробное объяснение, почему картинка именно такая — текст зависит от
активной физической модели (классика / полуклассика / квант / Белл).

### Физическое ядро

Единый интерфейс движка; реализация выбирается в рантайме:

- **Rust → WASM** (`physics-wasm/`) — основной движок: RK4-интегрирование траекторий,
  детерминированный PCG32, бинарный zero-copy протокол. Возвращает `ArrayBuffer`
  с f64-массивами (позиции hero-частиц, попадания, истории измерений).
- **TypeScript-фоллбэк** (`src/physics/engine.ts`) — эталонная реализация той же математики
  (та же последовательность вызовов RNG), используется, если wasm-модуль недоступен,
  и в юнит-тестах. Бейдж в шапке показывает активный движок: `Rust·WASM` или `JS`.

Магнитное поле каскада — композит аналитических полей аппаратов: в локальной системе
каждого магнита B = env(x)·win(r⊥)·(0, −G·y, B₀+G·z) (div-free и curl-free в 1-м порядке),
повёрнутой на θ вокруг оси пучка. Печь задаёт максвелловское распределение скоростей,
апертуру и расходимость; всё в СИ (агома серебра, магнетон Бора). Сцена: 1 unit = 1 мм.

Квантовый режим: пакет рождается в щели, на входе каждого магнита расщепляется на две
гауссовы ветви с весами cos²(θ_rel/2); центры ветвей следуют эренфестовской (классической)
кинематике, огибающие расплываются со временем. ψ(x,z,t) рисуется аддитивной тепловой
картой (синий/оранжевый — знак проекции спина), профиль на экране — в панели статистики.

## Запуск

Требуется Node 18+ и pnpm.

```bash
pnpm install        # в корне
pnpm dev            # http://localhost:5173
```

WASM-движок уже собран и закоммичен в `frontend/public/wasm`. Пересборка после правок Rust:

```bash
pnpm build:wasm     # требует cargo + wasm32-unknown-unknown + wasm-pack
```

Без Rust-тулчейна приложение всё равно работает на JS-фоллбэке.

## Тесты

```bash
pnpm test           # vitest (физика TS: 22 теста) + cargo test (физика Rust: 6 тестов)
```

Проверяется: симметрия двух пятен и совпадение расщепления с аналитикой; сплошная полоса
в классике; равные 4 ветви при 90°; вероятности cos²(θ/2); нормировка ψ; детерминизм;
S ≈ 2√2 у квантовой модели Белла и S ≤ 2 у локальной; корреляции −cosΔ; честный
пропуск триалов при η < 1; исчезновение нарушения при V < 0.71.

## Управление

- **ЛКМ по магниту** — выбор (гизмо вращения вокруг оси пучка, snap 5°)
- **Колесо / drag** — камера (OrbitControls)
- Слайдеры каскада: угол θ, градиент ∂B/∂z, длина магнита, зазор, блокиратор
- Источник: скорость пучка, разброс, апертура, расходимость; положение экрана
- Пресеты: «Оригинал 1922», «Каскад SGz→SGx», «Фильтр спина», «Три по 45°», «Квантовый пакет»

## Приближения (честно)

- Полуклассика: коллапс спина на входе магнита (сильное поле), прецессия Лармора не
  анимируется (спин «прилипает» к оси n(θ) после измерения)
- Классика: постоянный μ̂ (прецессионное усреднение), градиент окна полюсов не учитывается
- Квантовый режим — аналитическая аппроксимация (не численное решение уравнения Паули);
  дифракция на щели моделируется гауссовой огибающей
- Дефолтный градиент (1500 Т/м) завышен против исторического эксперимента ради
  читаемой картинки — реальное расщепление было ~0.2 мм
