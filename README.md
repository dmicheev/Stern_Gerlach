# ⚛ Stern-Gerlach

**[→ Открыть онлайн-демо](https://dmicheev.github.io/Stern_Gerlach/)**

![Stern-Gerlach](docs/screenshot-main.png)

Интерактивная 3D-эмуляция опыта Штерна-Герлаха и **теста неравенства Белла** (CHSH)
по мотивам эксперимента Хенсена (Hensen et al., Nature 526, 682 (2015)).

Два режима (переключатель в шапке):

## 1. Каскад (дерево пучков)

Пучок атомов серебра из печи проходит через магниты и оставляет «осадок» на экране.
**Аппараты ставятся на конкретный пучок**: источник даёт корневой луч, каждый магнит
делит его на два выходных (↑/↓) со своими траекториями; следующий магнит привязывается
к выбранной ветви (селектор «Пучок» в карточке), встаёт на её геометрию и видит только
её частицы. Классика предсказывает сплошную полосу — квантовая механика даёт
дискретные пятна.

- Маршрутизация по пучкам: дерево любой глубины (SGz → ветвь ↑ → SGx → …), лучи
  ветвей рисуются в 3D до экрана, позиции магнитов на ветвях вычисляются из отклонения
- **Три модели**: классика (сплошная полоса), полуклассика (квантованный спин, ветви
  cos²(θ/2)), квантовая (волновой пакет ψ(x,z,t) — суперпозиция гауссовых ветвей)
- «Классика-призрак», гистограмма попаданий (±120 мм), таблица ветвей, таймлайн

## 2. Белл CHSH (запутанные пары)

**Идеализированная симуляция эксперимента CHSH с моделированием эффективности
детекторов η и видности V** (по мотивам Hensen et al., Nature 526, 682 (2015)):
источник запутанных пар |ψ⁻⟩ в центре, две станции (A и B), каждая с **двумя
базисами** (a₀,a₁ / b₀,b₁), случайный выбор базиса на каждую пару (имитация
квантового генератора случайных чисел, QRNG), двухпортовые детекторы, живая
статистика CHSH:

- **Квантовая модель**: E(a,b) = −cos(θa−θb) → S до 2√2 (нарушение неравенства)
- **Локальный реализм**: скрытые параметры φ → S ≤ 2 при полной детекции (теорема
  Белла) — та же установка, другая «физика»: прямая демонстрация, почему
  запутанность нельзя свести к предопределённым значениям
- Слайдеры «дыр»: эффективность детекторов η и видность V
- Живая таблица корреляций ⟨x·y⟩ по 4 комбинациям базисов, бегущий график S(N)
  с линиями 2 и 2√2, пресет «Hensen 2015» (0°/90° / −139.7°/+139.7°)

⚠️ **Это не loophole-free тест.** Статистика CHSH строится только по событиям,
где сработали оба детектора (post-selection). При η < 1 это ровно сценарий «дыры
детекции» / предположения честной выборки: даже локальная модель может превысить
S = 2 не из-за отказа локального реализма, а из-за отбрасывания «неудобных»
событий — симуляция именно **демонстрирует** эту дыру, а не закрывает её.
Пространственноподобное разделение станций, времена переключения базисов,
реальные детекторные таймлайны и memory-эффекты не моделируются (базисы просто
разыгрываются на каждую пару). «Бездырочным» был реальный эксперимент Хенсена
2015 года, а не эта учебная модель.

Скриншот рабочего режима: `docs/sg-bell-quantum.png`.

## Три модели: чем отличается расчёт (простыми словами)

| | Классика | Полуклассика | Квант |
|---|---|---|---|
| Атом | шарик со «стрелкой» μ | шарик с квантовым спином | волновой пакет ψ |
| В магните | ничего не происходит: сила зависит от ориентации стрелки | «бросок монетки», спин прилипает к ±n | пакет делится на суперпозицию ветвей |
| На экране | сплошная полоса | два пятна (накопление Монте-Карло) | два расплывающихся пятна \|ψ\|² |

**Классика — «шарики со стрелками».** Атом — намагниченный шарик, у которого
стрелка (магнитный момент μ) торчит в случайную сторону и не меняется в полёте.
Никакого кубика: сила F = ∇(μ·B) непрерывно зависит от того, куда стрелка
смотрит, и каждый атом отклоняется ровно на «свою» величину. Стрелки у атомов
смотрят во все стороны равномерно — отклонения заполняют диапазон непрерывно,
получается сплошная полоса.

**Полуклассика — «шарики с кубиком».** Траектории по-прежнему классические,
но спин живёт по квантовым правилам. На входе в магнит разыгрывается исход:
P(↑) = (1 + s·n)/2 (правило Борна), спин мгновенно «прилипает» к ±n (коллапс),
и дальше сила ±μ_B·G ведёт шарик по обычной траектории. Картина на экране —
накопление тысяч таких случайных прогонов (Монте-Карло).

**Квант — «размазанная волна, которая делится, а не выбирает».** Отдельных
атомов нет: весь пучок — один волновой пакет ψ. В магните ничего не выбирается:
пакет расщепляется на две ветви с весами cos²(θ/2) и sin²(θ/2), и обе живут
одновременно — атом как бы проходит через оба порта сразу. Блокиратор не ловит
шарики, а выжигает целую ветвь (проекция состояния). Средние траектории ветвей
классические (теорема Эренфеста), огибающие расплываются со временем. Честная
дисперсия огибающей складывается из трёх слагаемых — начальной ширины щели,
классического разброса скоростей и собственного квантового расплывания
σ ∝ ħt/2mσ₀; для тяжёлых атомов серебра квантовое слагаемое — нанометры на фоне
миллиметров классического разброса, и вклад каждого слагаемого виден в панели
статистики. Попадания на экран сэмплируются из плотности |ψ|².

**Что общего.** При большом числе частиц гистограмма полуклассики сходится
ровно к профилю |ψ|² квантовой модели — вероятность cos²(θ/2) одна и та же.
Различается «онтология посередине»: полуклассика говорит «атом уже где-то
конкретно, мы просто не знаем где», квант — «атом реально в суперпозиции, пока
его не поймал экран». Оговорка: в квантовом режиме ветви складываются по
плотностям без интерференционных членов (аналитические гауссовы пакеты) —
модель про суперпозицию и проекцию, а не про фазы.

### Физическое ядро

Единый интерфейс движка; реализация выбирается во время выполнения:

- **Rust → WASM** (`physics-wasm/`) — основной движок: интегрирование траекторий
  методом Рунге-Кутты 4-го порядка (RK4), детерминированный генератор случайных
  чисел PCG32, компактный бинарный протокол (единственное копирование — на выходе
  из wasm-памяти; дальше JS работает с TypedArray-views поверх буфера, без
  поэлементных копий). Возвращает `ArrayBuffer` с массивами f64: покадровые
  позиции видимых в полёте частиц (подвыборка из ~400 для анимации, остальные —
  только в статистике), координаты попаданий и истории измерений спина.
- **Резервная реализация на TypeScript** (`src/physics/engine.ts`) — эталонная
  реализация той же математики (та же последовательность вызовов генератора
  случайных чисел), используется, если WASM-модуль недоступен, и в юнит-тестах.
  Индикатор в шапке показывает активный движок: `Rust·WASM` или `JS`.

Инвариант проекта: **при одинаковом конфиге и seed реализации JS и WASM обязаны
давать идентичный результат** — это проверяется тестом parity
(`src/physics/__tests__/parity-wasm.test.ts`) на наборе фиксированных конфигураций.

Магнитное поле каскада — композит аналитических полей аппаратов: в локальной системе
каждого магнита B = env(x)·win(r⊥)·(0, −G·y, B₀+G·z) (без дивергенции и ротора
в первом порядке), повёрнутой на θ вокруг оси пучка. Отдельно оговорено: поле для
рендера (fieldAt) и сила в движке (forceClassical) — это связанные, но не тождественные
приближения: градиент окна полюсов win(r⊥) в силе намеренно опущен (мал вблизи оси),
поэтому вдали от оси F ≠ ∇(μ·B_rendered) — см. комментарий в `src/physics/field.ts`.
Печь задаёт максвелловское распределение скоростей, апертуру и расходимость; все
величины — в СИ (атом серебра, магнетон Бора). Масштаб сцены: 1 единица = 1 мм.

Квантовый режим — **аналитическая аппроксимация волнового пакета** («Pauli-inspired»,
не численное решение уравнения Паули): пакет рождается в щели, на входе каждого
магнита расщепляется на две гауссовы ветви с весами cos²(θ_rel/2); центры ветвей
следуют эренфестовской (классической) кинематике. Ветви не несут относительной фазы
и складываются по плотностям — интерференции в модели нет. Огибающая каждой ветви —
дисперсный гауссиан, дисперсия которого складывается из трёх независимых источников:
начальный размер щели σ₀, классический разброс скоростей (тепловой + расходимость
источника — доминирует для тяжёлого Ag) и собственно квантовое расплывание
σ₀·(ħt/2mσ₀²) — для атомов серебра это нанометры на фоне миллиметров, и панель
статистики честно показывает вклад каждого слагаемого. Слабые ветви (< 1e-10)
отбрасываются, и отброшенная масса явно сообщается. ψ(x,z,t) рисуется аддитивной
тепловой картой (синий/оранжевый — знак проекции спина), профиль на экране —
в панели статистики; попадания сэмплируются из плотности (аппроксимация, не полный
детектор вероятностного тока).

## Запуск

Требуется Node.js 18+ и pnpm. Rust не нужен — WASM-движок уже собран
и лежит в репозитории. **Одна команда** — при первом запуске зависимости
установятся сами:

```bash
pnpm dev        # http://localhost:5173 (аналогично pnpm start)
```

Пошаговая инструкция для любой ОС (Windows / macOS / Linux), включая установку
Node.js и pnpm с нуля, а также ответы на частые вопросы: **[docs/INSTALL.md](docs/INSTALL.md)**.

## Публикация в интернете

```bash
pnpm build      # статическая сборка → frontend/dist (зависимости поставятся сами)
```

- **GitHub Pages** — в репозитории настроена автосборка
  (`.github/workflows/deploy.yml`): Settings → Pages → Source: GitHub Actions
- **Netlify/Vercel/свой сервер** — просто разместите содержимое `frontend/dist`
  (подробности и варианты для новичков — в [docs/INSTALL.md](docs/INSTALL.md))

Пересборка WASM после правок Rust — обязательно, иначе в браузере останется
старая физика:

```bash
./scripts/build-wasm.sh              # переносимо: rustup (target wasm32) + wasm-pack
# или, на macOS/Apple Silicon с поломанным двойным rustc:
./scripts/build-wasm-macos-arm64.sh  # требует rustup-тулчейн + brew install lld
```

Подробности и решение проблем сборки: `docs/troubleshooting-wasm.md`.

Без Rust-тулчейна приложение всё равно работает на резервной JS-реализации.

## Тесты

```bash
pnpm test           # vitest (физика TS: 53 теста) + cargo test (физика Rust: 7 тестов)
```

Проверяется: симметрия двух пятен и совпадение расщепления с аналитической формулой;
сплошная полоса в классике; равные 4 ветви при 90°; вероятности cos²(θ/2); нормировка ψ;
детерминизм; S ≈ 2√2 у квантовой модели Белла и S ≤ 2 у локальной; корреляции −cosΔ;
честный пропуск событий при η < 1; исчезновение нарушения при V < 0.71.

Дополнительно: **parity-тест JS ↔ WASM** (одинаковый конфиг + seed → идентичный
результат на наборе из 5 конфигураций), физические инварианты (P↑+P↓ = 1,
сохранение полной вероятности ветвей с учётом отброшенной массы, ⟨z⟩ = 0 в классике),
инвариантность поворота расщепления для 0°/45°/90°/135°/180° и guard от
устаревших результатов worker'а (гонка «медленный ответ перезаписывает новый»).

## Управление

- **Левая кнопка мыши (ЛКМ) по магниту** — выбор (гизмо вращения вокруг оси пучка, шаг привязки 5°)
- **Колесо мыши / перетаскивание** — камера (OrbitControls)
- Слайдеры каскада: угол θ, градиент ∂B/∂z, длина магнита, зазор, блокиратор
- Источник: скорость пучка, разброс, апертура, расходимость; положение экрана
- Пресеты: «Оригинал 1922», «Каскад SGz→SGx», «Фильтр спина», «Три по 45°», «Квантовый пакет»

## Приближения (честно)

- Полуклассика: коллапс спина на входе магнита (сильное поле), прецессия Лармора не
  анимируется (спин «прилипает» к оси n(θ) после измерения)
- Классика: постоянный μ̂ (прецессионное усреднение), краевые эффекты оконной функции
  полюсов не учитываются; сила в движке и отрисовываемое поле — согласованные, но
  не тождественные приближения (градиент окна полюсов в силе опущен — мал вблизи оси)
- Квантовый режим — аналитическая аппроксимация (не численное решение уравнения Паули);
  дифракция на щели моделируется гауссовой огибающей; ветви не имеют фазы —
  интерференционные члены отсутствуют по построению (суммируются плотности);
  наблюдаемое «расплывание» доминируется классическим разбросом скоростей источника,
  собственно квантовая дисперсия для Ag — нанометры (панель статистики показывает
  вклад каждого слагаемого); попадания на экран сэмплируются из плотности пакета,
  а не из вероятностного тока j = ħ/m·Im(ψ*∇ψ)
- Белл/CHSH — идеализированная статистическая модель: post-selection по событиям
  с двумя сработавшими детекторами (при η < 1 — демонстрация дыры детекции,
  не её закрытие), пространственноподобное разделение и реальные таймлайны
  станций не моделируются
- Градиент по умолчанию (1500 Т/м) завышен против исторического эксперимента ради
  читаемой картинки — реальное расщепление было ~0.2 мм
