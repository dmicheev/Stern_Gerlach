# Установка и запуск — пошаговая инструкция

Это руководство для тех, кто никогда не работал с Node.js. Программа запускается
на **Windows, macOS и Linux** одинаково: отличается только способ установки
Node.js (шаг 1). Rust и компиляторы **не нужны** — физический движок уже
собран в WebAssembly и лежит в репозитории.

Если вы просто хотите **разместить программу на сайте** — переходите сразу
к разделу [«Публикация в интернете»](#публикация-в-интернете).

---

## Шаг 1. Установите Node.js

Нужна версия **18 или новее** (рекомендуем LTS 20/22).

### Windows
1. Откройте https://nodejs.org
2. Скачайте версию с пометкой **LTS** (файл `.msi`).
3. Запустите установщик — везде «Далее», ничего менять не нужно.
4. Проверка: откройте **PowerShell** (Пуск → введите «PowerShell») и введите:
   ```
   node -v
   ```
   Должно вывести что-то вроде `v22.11.0`.

### macOS
1. Откройте https://nodejs.org и скачайте LTS-установщик (`.pkg`), установите.
2. Откройте **Терминал** (Cmd+Пробел → «Терминал») и проверьте:
   ```
   node -v
   ```
   Если вы пользуетесь Homebrew, можно вместо этого: `brew install node@22`.

### Linux (Ubuntu/Debian)
```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v
```
Для других дистрибутивов берите Node.js 18+ из своего менеджера пакетов
или с nodejs.org.

## Шаг 2. Включите pnpm

pnpm — менеджер пакетов, который скачивает библиотеки проекта.
В терминале (PowerShell/Терминал/bash) выполните один раз:

```bash
corepack enable
corepack prepare pnpm@latest --activate
pnpm -v
```

Если `corepack` не найден (очень старый Node) — обновите Node.js (шаг 1)
или установите pnpm напрямую:

```bash
npm install -g pnpm
```

## Шаг 3. Получите код программы

**Вариант А — без git (проще всего):**
1. Откройте страницу репозитория на GitHub.
2. Зелёная кнопка **Code → Download ZIP**.
3. Распакуйте архив в любую папку, например `Stern_Gerlach`.

**Вариант Б — через git:**
```bash
git clone https://github.com/dmicheev/Stern_Gerlach.git
cd Stern_Gerlach
```

## Шаг 4. Запустите

Из папки проекта (внутри распакованного/склонированного репозитория) — **одна команда**:

```bash
pnpm dev
```

При первом запуске программа сама скачает зависимости (нужен интернет,
~1–2 минуты) и затем стартует. Появится строка `Local: http://localhost:5173/` —
откройте этот адрес в браузере (Chrome, Firefox, Edge, Safari — любой
современный). Не закрывайте окно терминала, пока работаете с программой.

Если авто-установка не сработала (например, нет доступа в сеть у установщика),
поставьте зависимости вручную и запустите:

```bash
pnpm --dir frontend install
pnpm dev
```

Остановка: нажмите в терминале **Ctrl+C** (Windows/Linux) или **Cmd+C** (macOS).

## Публикация в интернете

Программа — обычный статический сайт. Соберите её одной командой:

```bash
pnpm build
```

Готовые файлы появятся в папке **`frontend/dist`** — их можно разместить
где угодно. Важно: просто открыть `index.html` двойным кликом **нельзя**
(браузер не даст загрузить WebAssembly с диска) — нужен любой веб-сервер.

### Вариант 1. GitHub Pages (автоматически, рекомендуем)

В репозитории уже есть автосборка (`.github/workflows/deploy.yml`):
1. Откройте настройки репозитория на GitHub → **Settings → Pages**.
2. В пункте **Source** выберите **GitHub Actions**.
3. Готово. При каждом обновлении ветки `main` сайт пересобирается сам.
   Адрес: `https://<логин>.github.io/Stern_Gerlach/`.

### Вариант 2. Netlify (перетащить папку, без git)

1. Соберите `frontend/dist` (команда выше).
2. Откройте https://app.netlify.com/drop
3. Перетащите папку `dist` в окно браузера — сайт сразу получит адрес вида
   `https://что-то.netlify.app`.

### Вариант 3. Vercel

```bash
npm install -g vercel
cd frontend
vercel
```
Ответьте на пару вопросов — получите публичный адрес.

### Вариант 4. Своей сервер (nginx, Apache, университетский хостинг)

Скопируйте содержимое `frontend/dist` в корень сайта (например, `/var/www/html`).
Пример для nginx: `sudo cp -r frontend/dist/* /var/www/html/`.

## Частые вопросы

**`pnpm: command not found`** — выполните шаг 2, затем закройте и заново
откройте терминал.

**`ERR_PNPM_IGNORED_BUILDS: esbuild`** — в актуальной версии проекта уже
исправлено (`frontend/pnpm-workspace.yaml`). Если сообщение осталось —
выполните `pnpm --dir frontend approve-builds` и разрешите esbuild.

**`pnpm --dir frontend install` падает с ошибками версий** — проверьте
`node -v`: нужна версия 18+. Старую Node проще всего обновить установщиком
с nodejs.org.

**Порт 5173 занят** (`Port 5173 is in use`) — запустите на другом порту:
`pnpm --dir frontend dev -- --port 5174`.

**Установка зависимостей проходила не в той папке** — команда `pnpm dev` сама
ставит зависимости во вложенную папку `frontend` при первом запуске; вручную
используйте `pnpm --dir frontend install`. Команда `pnpm install` в корне
репозитория ничего не устанавливает.

**Медленный или корпоративный интернет** — если скачивание пакетов
блокируется, попробуйте `pnpm --dir frontend install --proxy http://адрес:порт`
(адрес прокси уточните у администратора сети).

**Нужны ли Rust или cargo?** Нет. WebAssembly-движок уже собран и лежит
в репозитории. Rust нужен только тем, кто меняет физику в `physics-wasm/`
(см. `docs/troubleshooting-wasm.md`).

## Краткая шпаргалка

```bash
# один раз после установки Node.js
corepack enable && corepack prepare pnpm@latest --activate

# каждый запуск программы (зависимости поставятся сами при первом запуске)
pnpm dev                      # http://localhost:5173

# сборка для публикации
pnpm build                    # результат: frontend/dist
```
