# Cascade Simulation (режим «Каскад») — delta

## Purpose

Дельта изменения `classical-blocker`: блокиратор работает во всех физических
моделях, включая классическую (геометрическое срезание половины пучка).

## Requirements

### Requirement: Параметры аппаратов и источника (модифицировано)

Для каждого аппарата настраиваются: угол θ (вращение гизмо вокруг оси пучка
с шагом 5°), градиент ∂B/∂z, длина магнита, зазор, блокиратор порта (нет/↑/↓).
Для источника: скорость пучка, разброс скоростей, апертура, расходимость,
положение экрана.

Блокиратор — физическая пластина на выходе магнита, работающая во всех
физических моделях: в полуклассике/квантовом режиме поглощается вся ветвь
измерения (↑ или ↓); в классической модели поглощаются частицы, поперечное
смещение которых вдоль оси аппарата n(θ) в плоскости блокиратора попадает
на заблокированную сторону (d > 0 для ↑, d < 0 для ↓).

#### Acceptance Criteria

- **WHEN** пользователь выбирает магнит ЛКМ и вращает гизмо
- **THEN** угол θ обновляется в конфигурации (кратный 5°) и физика пересчитывается
- **WHEN** для аппарата в полуклассическом режиме включён блокиратор верхнего порта
- **THEN** частицы ветви ↑ поглощаются и не попадают в статистику экрана
- **WHEN** в классическом режиме включён блокиратор верхнего порта
- **THEN** частицы, отклонённые в верхнюю половину (d > 0 вдоль n(θ)) на выходе магнита, поглощаются (~50% пучка), а попадания на экран сосредоточены в нижней половине
