# Cascade-Simulation Specification (дельта: типы аппаратов и интерферометр)

## Purpose

Дельта изменения `coherent-quantum-branches`: каскад получает типы аппаратов
(анализатор/магнит/рекомбинер), merged-пучки и пресет интерферометра ШГ.

## Requirements

### Requirement: Типы аппаратов в каскаде

Каждый аппарат каскада имеет тип: 'analyzer' (измеряющий анализатор —
поведение по умолчанию, обратная совместимость конфигураций без поля kind),
'magnet' (когерентный расщепитель — не измеряет, which-path отсутствует),
'recombiner' (сливает пару пучков родителя в merged-пучок; только квантовый
режим, в остальных — пометка в UI и пропуск траекторными движками). Для
рекомбайнера доступна ручка дополнительной разности фаз phaseShiftDeg (0..360°,
действует на верхнее плечо).

#### Acceptance Criteria

- WHEN конфигурация не содержит поля kind
- THEN аппарат ведёт себя как 'analyzer' (прежнее поведение сохранено)
- WHEN пользователь меняет тип аппарата на 'magnet' в квантовом режиме
- THEN расщепление остаётся, но порты сохраняют когерентность
- WHEN recombiner присутствует в классическом/полуклассическом режиме
- THEN частицы пролетают его насквозь, UI показывает предупреждение

### Requirement: Пресет «Интерферометр ШГ»

Пресет quantum-режима: печь → фильтр (0°, blockedPort down, пониженный
градиент) → когерентный магнит 90° → рекомбайнер 90° (merge пары) →
анализатор 0° → экран. Слайдер phaseShiftDeg рекомбайнера управляет разностью
фаз ветвей; счётчики портов финального анализатора (гистограмма экрана)
осциллируют с периодом 360°.

#### Acceptance Criteria

- WHEN пользователь применяет пресет и сканирует фазу рекомбайнера
- THEN доли спин-компонент финального анализатора меняются периодически
- WHEN между сплиттером и рекомбайнером блокируется порт
- THEN интерференция исчезает (контраст → 0)
