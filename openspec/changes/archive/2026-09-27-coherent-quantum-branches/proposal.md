# coherent-quantum-branches

## Why

Раздел «Приближения и ограничения» README честно фиксирует: у ветвей
квантового режима нет фаз, интерференционные члены отсутствуют по построению,
попадания сэмплируются из плотности, а не из тока. Модель показывает суперпозицию
и проекцию, но не физику когерентности. Дополнительно в `quantum.ts` найден
латентный дефект: вероятность порта на анализаторе считалась как cos²(Δθ/2)
только по оси родителя, без знака спина — для down-ветви под косым углом
вероятности инвертируются (cos² вместо sin²).

## What

Ветви квантового режима несут комплексные амплитуды: модуль — вес, фаза —
действие вдоль классической траектории (кинетика + спин-зависимый потенциал
U = −s·μ_B(B₀+G·q); ларморовская фаза B₀ входит автоматически). Спиновые
состояния — полные спиноры ±n̂(θ), проекции на анализаторах — комплексные
матричные элементы ⟨χ±|χ⟩ (исправляет знак down-ветвей). Вводятся
когерентные группы: аппарат `magnet` расщепляет чистую ветвь когерентно
(без which-path), `analyzer` измеряет (порты декогерируют); неполяризованный
исток остаётся смесью ½/½. Плотность |Σ aᵢe^{iφᵢ}ψᵢ|² считается с попарными
комплексными перекрытиями гауссиан и фазовым наклоном импульса — при
разделённых пакетах модель поточечно воспроизводит прежнюю. Новый аппарат
`recombiner` (только квантовый режим) сливает пару пучков `${X}:up`+`${X}:down`
в `${X}:merged` двухкусковым профилем градиента −G/+G₂ (возвращает относительную
координату пары в ноль) и имеет ручку фазовой пластинки phaseShiftDeg.
Попадания: времена — из потока через экран (при общей v_x ток j_x = v_x·ρ),
координаты — из когерентной маргинали (CDF), спин — Борн по локальному спинору
вдоль оси экранной системы. Пресет «Интерферометр ШГ»: фильтр → когерентный
магнит 90° → рекомбайнер → анализатор 0°; скан фазы осциллирует счётчики портов.

## How

- `frontend/src/physics/quantum.ts`: сегментная кинематика с замкнутыми формами
  позиции/скорости/действия; спиноры и когерентные группы; рекомбайнер;
  когерентные evalRho/evalProfile/evalAxisProfile; сэмплирование из тока со
  спин-Борном
- `frontend/src/physics/types.ts`: ApparatusKind + kind + phaseShiftDeg;
  `beams.ts`: merged-пучки (парсинг, центры, лучи); `engine.ts` + `worker.ts`:
  рекомбайнеры отфильтрованы из траекторных движков (паритет JS↔WASM сохранён,
  Rust не меняется)
- `store.ts`/`presets.ts`: kind в makeApparatus, нормализация attachTo
  `:merged`; пресет интерферометра
- UI: селектор типа аппарата и слайдер фазы в CascadePanel, маркировка
  моделей (R/C, цвета полюсов), i18n RU/EN
- Тесты (vitest): спиноры, знако-корректные вероятности down-ветвей,
  когерентное/некогерентное расщепление, точность рекомбинации, осцилляция
  портов по фазе (контраст ≈ 1), блокиратор убивает пару, merged-лучи
- README: раздел «Приближения и ограничения» переписан (что теперь честно
  моделируется и что осталось приближением)

## Impact

Существующие пресеты (только анализаторы, неполяризованный исток) воспроизводят
прежние результаты поточечно; поведение без когерентных магнитов/рекомбайнеров
не меняется, кроме исправления знака вероятностей down-ветвей (покрыто тестом).
Руст/WASM не затронут (рекомбайнеры выфильтрованы до движка). Тепловая карта
ψ-поля: асимметрия теперь — ожидание σ_z локального спинора (раньше — знак
порта), что физичнее и визуализирует когерентность.
