# Screen Analysis Modal (разбор экрана по клику)

## Purpose

Специфицирует модальное окно разбора детекций: открытие по клику в обоих
режимах, состав графиков (2D-распределение и гистограмма/столбцы),
объяснения «почему» из базы подсказок и поведение модалки.

## Requirements

### Requirement: Открытие по клику

Клик по экрану-детектору (каскад) или по детекторной сборке станции (Белл)
открывает модальное окно разбора. Кликабельная зона — невидимая плита вокруг
объекта, ловящая клики с любого ракурса; наведение меняет курсор на pointer.
Закрытие: кнопка ✕, Escape, клик по фону (не по карточке).

#### Acceptance Criteria

- **WHEN** пользователь кликает по экрану-детектору
- **THEN** открывается модалка «Экран-детектор · разбор осадка»
- **WHEN** пользователь кликает по детекторам станции A или B в режиме Белла
- **THEN** открывается модалка соответствующей станции («Станция A · разбор детекций»)

### Requirement: Содержимое — каскад

Слева 2D-распределение попаданий (вид на пластину, оси z × y в мм, высота
пропорциональна реальным пропорциям экрана, точки окрашены по ветви спина),
справа гистограмма N(z) со стеком по ветвям. Оба графика рендерятся
в разрешении devicePixelRatio и перестраиваются при ресайзе.

#### Acceptance Criteria

- **WHEN** модалка открыта во время воспроизведения
- **THEN** графики и счётчики (t, N) обновляются по текущему времени

### Requirement: Содержимое — Белл

Слева детекции станции: колонки по базисам θ₀/θ₁, внутри каждой половины
↑/↓, цвет по спину, серые точки внизу — пропуски по η. Справа столбцы
исходов по базисам с пунктирной линией 50% и счётчиком пропусков.

#### Acceptance Criteria

- **WHEN** набрана статистика в квантовой модели
- **THEN** столбцы θ₀↑/θ₀↓/θ₁↑/θ₁↓ примерно равны (~50% каждый)

### Requirement: Объяснение «почему»

Под графиками — раздел «Почему картинка именно такая» с блоками из базы
учебных подсказок, зависящими от активной модели: каскад — блок модели
(классика/полуклассика/квант) + чтение гистограммы; Белл — базисы станции,
модель (синглет/локальный реализм) и корреляция ⟨x·y⟩. Язык — текущий RU/EN.

#### Acceptance Criteria

- **WHEN** пользователь переключает физическую модель и открывает разбор
- **THEN** объяснение соответствует выбранной модели

### Requirement: Поведение модалки

Модалка не блокирует фоновую симуляцию (графики живые), закрывается по
Escape; клик по затемнённому фону закрывает только при попадании именно
в фон.

#### Acceptance Criteria

- **WHEN** пользователь кликает в затемнённую область вне карточки
- **THEN** модалка закрывается, симуляция продолжалась всё время без пауз
