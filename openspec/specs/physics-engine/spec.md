# Physics Engine (физическое ядро)

## Purpose

Специфицирует расчётное ядро: единый интерфейс с двумя эквивалентными
реализациями (Rust→WASM и TypeScript), выполнение в Web Worker, физическую
модель поля каскада и обязательное покрытие юнит-тестами.

## Requirements

### Requirement: Единый интерфейс движка

Физическое ядро имеет единый интерфейс; реализация выбирается во время
выполнения: основной движок Rust → WASM (`physics-wasm/`) и резервная
реализация на TypeScript (`src/physics/engine.ts`). Если WASM-модуль не
загрузился, приложение прозрачно работает на резервной реализации; индикатор
в шапке показывает активный движок (`Rust·WASM` или `JS`).

#### Acceptance Criteria

- **WHEN** WASM-модуль недоступен
- **THEN** расчёт идёт на TypeScript-реализации и индикатор движка показывает `JS`

### Requirement: Эквивалентность реализаций

Обе реализации считают одинаковую математику с одинаковой последовательностью
вызовов генератора случайных чисел: при одинаковой конфигурации и seed
результаты совпадают.

#### Acceptance Criteria

- **WHEN** прогон повторяется с той же конфигурацией и seed
- **THEN** результаты (траектории, попадания, исходы) идентичны

### Requirement: Расчёты вне главного потока

Все тяжёлые расчёты (траектории, квантовый пакет, эксперимент Белла)
выполняются в Web Worker; UI остаётся отзывчивым. Пересчёт запускается
с дебаунсом (~120 мс) при изменении конфигурации.

#### Acceptance Criteria

- **WHEN** пользователь двигает слайдер параметра
- **THEN** пересчёт запускается один раз после паузы, а не на каждый тик слайдера

### Requirement: Физическая модель каскада

Магнитное поле — композит аналитических полей аппаратов: в локальной системе
магнита B = env(x)·win(r⊥)·(0, −G·y, B₀+G·z), повёрнутой на θ вокруг оси
пучка; поле без дивергенции и ротора в первом порядке. Печь задаёт
максвелловское распределение скоростей, апертуру и расходимость. Все
величины в СИ; масштаб сцены 1 единица = 1 мм.

#### Acceptance Criteria

- **WHEN** прогоняется полуклассическая модель с одним аппаратом
- **THEN** расщепление пятен совпадает с аналитической формулой, пятна симметричны и равны по счёту

### Requirement: Тесты физики

Юнит-тесты покрывают обе реализации: vitest (TS) и cargo test (Rust).
Проверяются: симметрия пятен и совпадение с аналитикой, сплошная полоса
в классике, равные ветви при 90°, вероятности cos²(θ/2), нормировка ψ,
детерминизм, S ≈ 2√2 (квант) и S ≤ 2 (локальная модель), корреляции −cosΔ,
честный пропуск событий при η < 1, исчезновение нарушения при V < 0.71.

#### Acceptance Criteria

- **WHEN** запускается `pnpm test`
- **THEN** все тесты vitest и cargo test проходят

### Requirement: Комплексные амплитуды и WKB-фазы ветвей

Ветви квантового режима несут комплексные амплитуды: модуль — вес, фаза —
действие вдоль классической траектории S = ∫[½m·v⊥² − U]dt с кусочно-постоянным
ускорением и спин-зависимым потенциалом U = −s·μ_B·(B₀+G·q) внутри магнита
(ларморовская фаза B₀ входит автоматически). Кинематика ветви — список
сегментов с замкнутыми формами для позиции, скорости и действия.

#### Acceptance Criteria

- **WHEN** две ветви одной когерентной группы перекрываются в точке
- **THEN** плотность содержит интерференционный член 2·Re(a_i a_j* ⟨χ_j|χ_i⟩ ψ_i ψ_j*)
- **WHEN** пакеты группы раздвинуты (перекрытие ~0)
- **THEN** плотность совпадает с суммой независимых ветвей (прежнее поведение)

### Requirement: Спинорные проекции на анализаторе

Чистые состояния ветвей — спиноры ±n̂(θ) в базисе σ_z; вероятности портов
анализатора — |⟨χ_±|χ⟩|² (комплексные матричные элементы). Для ветви со спином
−n̂(θ₀) и анализатора под углом θ вероятность «up» равна sin²((θ−θ₀)/2).

#### Acceptance Criteria

- **WHEN** ветвь спина −n̂(0°) проходит анализатор 45°
- **THEN** веса детей 0.5·sin²(22.5°) и 0.5·cos²(22.5°), а не наоборот

### Requirement: Когерентные группы и which-path

Аппарат kind='magnet' расщепляет чистую ветвь когерентно (дети наследуют
идентификатор когерентности cohId, амплитуды — проекции спинора родителя);
kind='analyzer' регистрирует which-path (дети одной группы в одном порте
остаются взаимно когерентны, разные порты и группы декогерируют).
Неполяризованный исток — смешанное состояние: дети некогерентны с весами ½/½.
Интерференция реализуется в непрерывной плотности через попарные комплексные
перекрытия гауссовых пакетов (с фазовым наклоном импульса); при нулевом
перекрытии результат совпадает с классической смесью.

#### Acceptance Criteria

- **WHEN** когерентная пара с ненулевым перекрытием проходит анализатор
- **THEN** массы портов содержат интерференционные члены и P(+) + P(−) = Σ|a_i|²
- **WHEN** исток неполяризован и все аппараты — анализаторы
- **THEN** веса ветвей и плотности воспроизводят прежнюю модель

### Requirement: Рекомбайнер

Аппарат kind='recombiner' (attachTo = `${X}:up|down`) сливает пучки `${X}:up` и
`${X}:down` в `${X}:merged` двухкусковым профилем градиента (−G, затем
вычисленный +G₂), возвращающим относительную координату пары (позицию и
скорость) точно в ноль; без измерения — спины, амплитуды и cohId сохраняются.
phaseShiftDeg добавляет e^{iφ} к «up»-члену пары (фазовая пластинка). Сила на
ветвь пропорциональна проекции спина на ось рекомбайнера (рассогласование осей
видимо деградирует сборку). Классический и полуклассический движки рекомбайнер
игнорируют (фильтр до движка, паритет JS↔WASM сохранён).

#### Acceptance Criteria

- **WHEN** когерентная пара входит в рекомбайнер с осью, равной оси сплиттера
- **THEN** на выходе центры и скорости пары совпадают (ε ≪ σ пакета)
- **WHEN** phaseShiftDeg меняется на 180°
- **THEN** вероятности портов последующего анализатора меняются существенно
  (контраст ≈ 1, комплементарные суммы = 1)
- **WHEN** между сплиттером и рекомбайнером блокируется одно плечо
- **THEN** пара не собирается и интерференция исчезает

### Requirement: Детектор из когерентной плотности

Попадания сэмплируются из когерентной плотности: времена — из потока через
плоскость экрана (при общей v_x ток j_x = v_x·ρ с интерференционными членами),
координаты — из когерентной маргинали (числовая CDF на кадр), спин попадания —
Борн по локальному спинору вдоль оси экранной системы (y-фактор несёт
which-path при поперечных расщеплениях). Для разделённых собственных ветвей
воспроизводит прежнюю статистику знаков; детерминирован для фиксированного seed.

#### Acceptance Criteria

- **WHEN** прогоняется конфигурация без когерентных магнитов/рекомбайнеров
- **THEN** статистика попаданий эквивалентна прежней (в пределах Монте-Карло)
