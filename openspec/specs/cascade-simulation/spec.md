# Cascade Simulation (режим «Каскад»)

## Purpose

Специфицирует основной режим приложения: прохождение пучка атомов серебра
через дерево SG-аппаратов с тремя физическими моделями, настройками
аппаратов и источника, накопительной статистикой и таймлайном.

## Requirements

### Requirement: Дерево пучков

Источник (печь серебра) даёт корневой пучок. Каждый установленный SG-аппарат
делит входной пучок на два выходных (↑/↓) со своими траекториями. Следующий
аппарат привязывается к конкретной ветви (селектор «Пучок» в карточке),
наследует её геометрию и обрабатывает только её частицы. Глубина дерева
не ограничена; привязка, создающая цикл, отклоняется.

#### Acceptance Criteria

- **WHEN** пользователь добавляет второй аппарат и привязывает его к выходу ↑ первого
- **THEN** аппарат встаёт на геометрию ветви ↑ (позиция вычисляется из отклонения) и обрабатывает только её частицы
- **WHEN** пользователь пытается привязать аппарат к его же потомку
- **THEN** привязка отклоняется, конфигурация не меняется

### Requirement: Три физические модели

Режим предлагает три модели: классика (непрерывный магнитный момент → сплошная
полоса на экране), полуклассика (квантованный спин, вероятности ветвей
cos²(θ/2)), квантовая (волновой пакет ψ(x,z,t) — суперпозиция гауссовых ветвей).
Модель переключается без перезагрузки приложения.

#### Acceptance Criteria

- **WHEN** выбрана классическая модель
- **THEN** осадок на экране и гистограмма показывают непрерывное распределение
- **WHEN** выбрана полуклассическая модель с одним аппаратом θ=0°
- **THEN** на экране два дискретных пятна с равными долями ~50%

### Requirement: Параметры аппаратов и источника

Для каждого аппарата настраиваются: угол θ (вращение гизмо вокруг оси пучка
с шагом 5°), градиент ∂B/∂z, длина магнита, зазор, блокиратор порта (нет/↑/↓).
Для источника: скорость пучка, разброс скоростей, апертура, расходимость,
положение экрана.

Блокиратор — физическая пластина на выходе магнита, работающая во всех
физических моделях: в полуклассике/квантовом режиме поглощается вся ветвь
измерения (↑ или ↓); в классической модели поглощаются частицы, поперечное
смещение которых вдоль оси аппарата n(θ) в плоскости блокиратора попадает
на заблокированную сторону (d > 0 для ↑, d < 0 для ↓).

#### Acceptance Criteria

- **WHEN** пользователь выбирает магнит ЛКМ и вращает гизмо
- **THEN** угол θ обновляется в конфигурации (кратный 5°) и физика пересчитывается
- **WHEN** для аппарата в полуклассическом режиме включён блокиратор верхнего порта
- **THEN** частицы ветви ↑ поглощаются и не попадают в статистику экрана
- **WHEN** в классическом режиме включён блокиратор верхнего порта
- **THEN** частицы, отклонённые в верхнюю половину (d > 0 вдоль n(θ)) на выходе магнита, поглощаются (~50% пучка), а попадания на экран сосредоточены в нижней половине

### Requirement: Статистика каскада

Панель статистики показывает: гистограмму попаданий N(z) с адаптивным
диапазоном по z (стек по ветвям, цвета совпадают с 3D), счётчики «на экране»
и «поглощено», таблицу ветвей (цепочка ↑/↓, счёт, доля). В квантовом режиме
вместо гистограммы — профиль |ψ|² на экране.

#### Acceptance Criteria

- **WHEN** идёт воспроизведение времени
- **THEN** гистограмма накапливается по моментам попаданий, как настоящий осадок

### Requirement: Таймлайн и «классика-призрак»

Воспроизведение: пуск/пауза, скорость, повтор (цикл), скраб времени.
Опциональный оверлей «классика-призрак» рисует те же траектории,
рассчитанные классической моделью (серым), для прямого сравнения.

#### Acceptance Criteria

- **WHEN** включён показ классики-призрака в полуклассическом режиме
- **THEN** в сцене видны серые классические траектории рядом с ветвями текущей модели
